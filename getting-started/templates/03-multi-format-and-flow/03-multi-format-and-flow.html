1 Format-responsive prefixes

Tailwind's sm: , md: , lg: are useless in PDFs — there's no viewport. Poli Page provides format prefixes instead:

TEMPLATE
<h1 class="text-xl a4:text-2xl letter:text-2xl a5:text-lg">
  Adaptive title
</h1>
<h1 class="text-xl a4:text-2xl letter:text-2xl 
  a5:text-lg">
  Adaptive title
</h1>
OUTPUT
A4 Adaptive Title
LETTER Adaptive Title
A5 Adaptive Title
2 You're now in landscape

Tailwind's sm: , md: , lg: are useless in PDFs — there's no viewport. Poli Page provides format prefixes instead:

TEMPLATE
<section class="poli-landscape">
  <h2>This whole section is landscape</h2>
  ...
</h1>

The reverse — poli-portrait inside a landscape document — also works. We use both: page 3 switches back to portrait via poli-portrait .

3 Why landscape mid-document?

Landscape gives you horizontal space. Use it for content that doesn't fit comfortably in portrait: wide tables, comparison spreads, panoramic images, dashboards.

@for (format of formats) { }
FORMAT WIDTH HEIGHT COMMON USE PRINT FIT RECOMMENDED
{{ format.name }} {{ format.width }} {{ format.height }} {{ format.commonUse }} {{ format.printFit }} {{ format.recommended }}

Notice the width

This 5-column table fills the landscape page. In portrait, it would overflow or shrink each column to unreadable widths.

4 Page break control
TEMPLATE
<section class="poli-break">
  <h2>This always starts on a new page</h2>
</section>

<div class="poli-avoid-break">
  <h3>Summary</h3>
  <p>Stays whole on one page.</p>
</div>
TRY THIS

Move the poli-last div to the first page and you'll see it still shows on the last. Now remove the poli-last - it now shows on the page you moved it to instead.

5 Back to portrait

The landscape section ended at the bottom of page 2. This page is portrait again, identical to page 1's orientation. You can switch back and forth as many times as a document needs.

Use the pattern thoughtfully: orientation changes are noticeable to the reader, so reserve them for content that genuinely benefits.
