DATA & CONTENT LESSON 02

Data & Content

This template is rendered from 02-data-and-content.json. All the content you see — the company name, the items list, the totals — comes from that file. Templates author the structure ; data fills it in.

Open both files side by side in the editor. As you type {{ , the editor autocompletes from the JSON.

1 Interpolation
TEMPLATE
{{ invoice.customer.name }}
OUTPUT
Acme Corp

The expression in {{ }} is JavaScript-like. You can call helpers, do arithmetic, chain property access — but the engine sandboxes execution: no network, no filesystem, no eval.

2 Looping with @for

Each row in the items table on page 3 is rendered by:

TEMPLATE
@for (item of invoice.items) {
  <tr> {{ item.name }} </tr>
}
OUTPUT
@for (item of invoice.items) { }
Item Name
{{ item.name }}
Note: Poli Page's @for does not require a track expression — the engine renders once and doesn't need keys.
TRY THIS

Open 02-data-and-content.json , add a new line item to invoice.items, save. The table grows in real time.

3 Conditionals and @if

Each row in the items table on page 3 is rendered by:

TEMPLATE
@if (discount) {
  <span class="...">
    {{ formatPercent(discount) }}
  </span>
}
OUTPUT
@if (discount) { -{{ formatPercent(discount) }} }
TRY THIS

In the data file, set discount: 0.15 on an item that doesn't have one. Save — the badge appears.

4 Multi-branch with @else if

Each row in the items table on page 3 is rendered by:

TEMPLATE
@if (status === "paid") {
  <span>Paid</span>
} @else if (status === "pending") {
  <span>Pending</span>
} @else {
  <span>Overdue</span>
}
OUTPUT
@if (status === 'paid') { Paid } @else if (status === 'pending') { Pending } @else { Overdue }

No @switch chain. Use @if / @else if / @else for multi-branch logic.

8 Last-page totals with poli-last

The totals box below only appears on the last page of the document. That's done with poli-last . If the line items grew and pushed the totals to page 5, this box would move with them.

Subtotal 14 790,00 €

TRY THIS

Move the poli-last div to the first page and you'll see it still shows on the last. Now remove the poli-last - it now shows on the page you moved it to instead.

Combined with poli-table-header , this is a common invoice pattern: header repeats per page, totals appear once at the end.
