## Release notes

### 0.10.0

- The Getting Started starter uses the redesigned Poli Page logo, and its `primary` colour is the new brand blue `#3979ca` (was `#4869a4`).

- The `poli-page.json` manifests no longer carry `project.version` (nor `cloud.track`). Projects are published into environments, so the field is gone.
